# Backrooms Arcade

Pagina web hecha con HTML, CSS y JavaScript sencillo.

## Incluye

- Diseno tipo app Android en pantalla de celular.
- Catalogo infinito: al bajar se cargan mas tarjetas.
- Buscador funcional.
- Filtros por etiqueta y plataforma.
- Etiquetas visibles en cada tarjeta.
- Espacios listos para agregar imagenes propias.

## Como agregar imagenes

1. Entra a la carpeta `imagenes`.
2. Agrega tus imagenes con estos nombres, o cambia las rutas en `index.html`:
   - `escape-backrooms.jpg`
   - `inside-rooms.jpg`
   - `vhs-hallways.jpg`
   - `fluorescent-maze.jpg`
   - `level-elevator.jpg`
   - `no-clip-runner.jpg`
   - `warm-liminal.jpg`
   - `hotel-endless.jpg`
   - `signal-lost.jpg`
   - `the-last-exit.jpg`
3. Si una imagen no existe, la pagina muestra un icono automaticamente.
