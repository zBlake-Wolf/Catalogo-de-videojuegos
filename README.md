# Backrooms Arcade

Pagina web hecha con HTML, CSS y un poco de JavaScript sencillo.

## Incluye

- Diseno tipo app Android en pantalla de celular.
- Estilo futurista inspirado en catalogos modernos de videojuegos.
- Tema Backrooms con tonos calidos.
- Buscador funcional y filtros por plataforma.
- 10 tarjetas de videojuegos con titulo, plataforma e imagen representativa.
- Diseno responsive para computadora y celular.
